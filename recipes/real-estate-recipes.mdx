# Real Estate API Use

## Terms

An API token proves which account sends a request. A project stores the data and settings for one property video. An image asset is one image stored in a project. A shot is one scene in the final video. A job is work that runs after the API sends a response.

## Request Rules

Use `https://backend.tensorpix.ai/api/v2/real-estate` as the base URL. Send `Authorization: Token API_TOKEN` in every request. Use `application/json` for JSON data. Use `multipart/form-data` for image files. The API only returns data owned by the account for the API token.

## Main Flow

1. Create a project with `POST /projects/`. Send a name such as `{"name": "12 Green Street"}`. The API returns `201`. Save the response `id` as `PROJECT_ID`. Use `PATCH /projects/PROJECT_ID/` to change property data or video settings.
2. Add images with `POST /projects/PROJECT_ID/assets/images/`. Send each file in a field named `images`. One request can contain from 1 to 60 images. The API returns `201` and a JSON list of image assets. Save each image asset `id`.
3. Create shots with `POST /projects/PROJECT_ID/shot-batches/`. Send `{"image_asset_ids": ["IMAGE_ASSET_ID_1", "IMAGE_ASSET_ID_2"]}`. The image asset ID order sets the shot order. The API returns `201` and a JSON list of shots. The API starts image study work for each shot. The client does not need to wait for this work.
4. Check the project with `GET /projects/PROJECT_ID/`. Start video work when `ready_for_generation` is `true`. Add `?include=cost_estimate` to also get `cost_estimate` and `cost_per_shot`.
5. Start video work with `POST /projects/PROJECT_ID/video-jobs/`. Send an empty JSON object. The API returns `202` when the job enters the work queue. Use the job URL from the `Location` response header or from `links.self` in the response body.
6. Send `GET` to the job URL every 5 seconds. The `status` value can be `queued`, `processing`, `completed`, `failed`, `cancelled`, or `expired`. Stop when the value is `completed`, `failed`, `cancelled`, or `expired`. Read `error_message` when the job does not complete. Use a client wait limit of 30 minutes.
7. After the job completes, send `GET /projects/PROJECT_ID/assets/videos/?tags=render_full&ordering=-created_at`. Read the first item in `results`. Use `file` as the video URL when `file` has a value. Use `external_url` when `file` has no value. The `file` URL can expire. Send the request again to get a new URL.

## Limits And Errors

Image asset IDs must belong to the same project. The account plan sets the project limit and shot limit. The account must have enough storage for image files. The account must have enough Credits before video work starts.

The API can return `400` for invalid data or low Credits. The API can return `401` for a missing or invalid API token. The API can return `404` when a resource does not exist or belongs to another account. The API can return `429` when the client sends requests too fast. The API can return `503` when the work queue cannot accept a job.

```python
"""Generate a real-estate video with local images or a Zillow listing."""

import os
import time
from pathlib import Path

import requests

API_URL = "https://backend.tensorpix.ai/api/v2/real-estate"
SOURCE = "images"
IMAGE_PATHS = [Path("/path/to/property.jpg")]
ZILLOW_URL = "https://www.zillow.com/homedetails/example/"

TERMINAL_JOB_STATUSES = {"completed", "failed", "cancelled", "expired"}


def wait_for_job(job_url: str, headers: dict[str, str]) -> dict:
    """Poll a job until it completes or fails."""
    deadline = time.monotonic() + 30 * 60

    while time.monotonic() < deadline:
        response = requests.get(job_url, headers=headers, timeout=60)
        response.raise_for_status()
        job = response.json()
        print(f"Job {job['id']}: {job['status']}")

        if job["status"] == "completed":
            return job
        if job["status"] in TERMINAL_JOB_STATUSES:
            message = job.get("error_message") or f"Job ended as {job['status']}"
            raise RuntimeError(message)

        time.sleep(5)

    raise TimeoutError("Job did not finish within 30 minutes.")


def create_project(headers: dict[str, str]) -> str:
    """Create a real-estate project and return its ID."""
    response = requests.post(
        f"{API_URL}/projects/",
        headers=headers,
        json={"name": "Simple API real-estate video"},
        timeout=60,
    )
    response.raise_for_status()
    return response.json()["id"]


def upload_images(project_id: str, headers: dict[str, str]) -> list[str]:
    """Upload local images and return their IDs."""
    if not IMAGE_PATHS:
        raise ValueError("Add at least one path to IMAGE_PATHS.")

    image_ids = []
    for image_path in IMAGE_PATHS:
        with image_path.open("rb") as image_file:
            response = requests.post(
                f"{API_URL}/projects/{project_id}/assets/images/",
                headers=headers,
                files={"images": (image_path.name, image_file)},
                timeout=60,
            )
        response.raise_for_status()
        image_ids.append(response.json()[0]["id"])
    return image_ids


def import_zillow_images(project_id: str, headers: dict[str, str]) -> list[str]:
    """Import Zillow images and return their IDs."""
    response = requests.post(
        f"{API_URL}/projects/{project_id}/property-import-jobs/",
        headers=headers,
        json={"url": ZILLOW_URL},
        timeout=60,
    )
    response.raise_for_status()
    wait_for_job(response.json()["links"]["self"], headers)

    response = requests.get(
        f"{API_URL}/projects/{project_id}/assets/images/",
        headers=headers,
        params={"page_size": 60, "ordering": "created_at"},
        timeout=60,
    )
    response.raise_for_status()
    payload = response.json()
    images = payload["results"] if isinstance(payload, dict) else payload
    return [image["id"] for image in images]


def create_shots(
    project_id: str,
    image_ids: list[str],
    headers: dict[str, str],
) -> None:
    """Create one shot for each image ID."""
    if not image_ids:
        raise RuntimeError("The project has no images.")

    response = requests.post(
        f"{API_URL}/projects/{project_id}/shot-batches/",
        headers=headers,
        json={"image_asset_ids": image_ids},
        timeout=60,
    )
    response.raise_for_status()


def generate_video(project_id: str, headers: dict[str, str]) -> str:
    """Generate the project video and return its URL."""
    response = requests.post(
        f"{API_URL}/projects/{project_id}/video-jobs/",
        headers=headers,
        json={},
        timeout=60,
    )
    response.raise_for_status()
    wait_for_job(response.json()["links"]["self"], headers)

    response = requests.get(
        f"{API_URL}/projects/{project_id}/assets/videos/",
        headers=headers,
        params={"tags": "render_full", "ordering": "-created_at", "page_size": 1},
        timeout=60,
    )
    response.raise_for_status()
    payload = response.json()
    videos = payload["results"] if isinstance(payload, dict) else payload

    if not videos:
        raise RuntimeError("The completed job has no rendered video.")

    video_url = videos[0].get("file") or videos[0].get("external_url")
    if not video_url:
        raise RuntimeError("The rendered video has no URL.")

    return video_url


def main() -> None:
    """Create a project, add images, and generate its final video."""
    token = os.environ["TENSORPIX_API_TOKEN"]
    headers = {"Authorization": f"Token {token}"}
    project_id = create_project(headers)

    if SOURCE == "images":
        image_ids = upload_images(project_id, headers)
    elif SOURCE == "zillow":
        image_ids = import_zillow_images(project_id, headers)
    else:
        raise ValueError("SOURCE must be 'images' or 'zillow'.")

    create_shots(project_id, image_ids, headers)
    video_url = generate_video(project_id, headers)
    print(video_url)


if __name__ == "__main__":
    main()
```
