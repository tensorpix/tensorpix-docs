# Real Estate API Use

## Terms

An API token proves which account sends a request.

A project stores the data and settings for one property video.

An image asset is one image stored in a project.

A shot is one scene in the final video.

A job is work that runs after the API sends a response.

## Base URL

Use this base URL for all real estate API requests.

```text
https://backend.tensorpix.ai/api/v2/real-estate
```

Send the API token in every request.

```http
Authorization: Token API_TOKEN
```

Use `application/json` for JSON request data.

Use `multipart/form-data` only for file upload requests.

## Main Flow

### 1. Create a project

Send a project name to `POST /projects/`.

```json
{
  "name": "12 Green Street"
}
```

The API returns `201` and the project data.

Save the `id` value as `PROJECT_ID`.

The project has default video settings.

Use `PATCH /projects/PROJECT_ID/` to change project data or video settings.

### 2. Add images

Send `POST /projects/PROJECT_ID/assets/images/` as a file upload request.

Use `images` as the field name for every image file.

One request can contain from 1 to 60 image files.

The API returns `201` and a JSON list of image assets.

Save each image asset `id` value.

The API does not create shots during this request.

### 3. Create shots

Send the image asset IDs to `POST /projects/PROJECT_ID/shot-batches/`.

```json
{
  "image_asset_ids": [
    "IMAGE_ASSET_ID_1",
    "IMAGE_ASSET_ID_2"
  ]
}
```

The list order sets the shot order.

The API returns `201` and a JSON list of shots.

The API starts image study work for each shot.

The client does not need to wait for that work before the next step.

### 4. Check the project

Send `GET /projects/PROJECT_ID/`.

Read `ready_for_generation` from the response.

Start video work only when `ready_for_generation` is `true`.

Use `GET /projects/PROJECT_ID/?include=cost_estimate` to also get `cost_estimate` and `cost_per_shot`.

### 5. Start video work

Send an empty JSON object to `POST /projects/PROJECT_ID/video-jobs/`.

```json
{}
```

The API returns `202` when the job enters the work queue.

The response body contains the job data.

The response `Location` header contains the job URL.

The same job URL is in `links.self`.

### 6. Wait for the job

Send `GET` to the job URL every 5 seconds.

The `status` field can be `queued`, `processing`, `completed`, `failed`, `cancelled`, or `expired`.

Stop when the status is `completed`, `failed`, `cancelled`, or `expired`.

Read `error_message` when the status is not `completed`.

Use a client wait limit of 30 minutes.

### 7. Get the video

After the job completes, send this request.

```http
GET /projects/PROJECT_ID/assets/videos/?tags=render_full&ordering=-created_at&page_size=1
```

Read the first item in `results`.

Use `file` as the video URL when `file` has a value.

Use `external_url` when `file` has no value.

The `file` URL can expire.

Send the same video asset request again to get a new URL.

## Important Rules

The API only returns data owned by the account for the API token.

Image files and image asset IDs must belong to the same project.

The account plan sets the project limit and shot limit.

The account must have enough storage for image files.

The account must have enough Credits before video work starts.

Do not start two full video jobs for the same project at the same time.

The API can return `400` for invalid data or low Credits.

The API can return `401` when the API token is missing or invalid.

The API can return `404` when a resource does not exist or belongs to another account.

The API can return `429` when the client sends requests too fast.

The API can return `503` when the work queue cannot accept a job.

See the [API documentation](api.md) for the API schema and all optional routes.

See the [simple real estate example](../examples/simple_real_estate_video.py) for a full Python client.

```python
"""Generate a real-estate video with local images or a Zillow listing."""

import os
import time
from pathlib import Path

import requests

API_URL = "https://backend.tensorpix.ai/api/v2/real-estate"
SOURCE = "images"
IMAGE_PATHS = [Path("/path/to/property.jpg")]
ZILLOW_URL = "https://www.zillow.com/homedetails/example/"

TERMINAL_JOB_STATUSES = {"completed", "failed", "cancelled", "expired"}


def wait_for_job(job_url: str, headers: dict[str, str]) -> dict:
    """Poll a job until it completes or fails."""
    deadline = time.monotonic() + 30 * 60

    while time.monotonic() < deadline:
        response = requests.get(job_url, headers=headers, timeout=60)
        response.raise_for_status()
        job = response.json()
        print(f"Job {job['id']}: {job['status']}")

        if job["status"] == "completed":
            return job
        if job["status"] in TERMINAL_JOB_STATUSES:
            message = job.get("error_message") or f"Job ended as {job['status']}"
            raise RuntimeError(message)

        time.sleep(5)

    raise TimeoutError("Job did not finish within 30 minutes.")


def create_project(headers: dict[str, str]) -> str:
    """Create a real-estate project and return its ID."""
    response = requests.post(
        f"{API_URL}/projects/",
        headers=headers,
        json={"name": "Simple API real-estate video"},
        timeout=60,
    )
    response.raise_for_status()
    return response.json()["id"]


def upload_images(project_id: str, headers: dict[str, str]) -> list[str]:
    """Upload local images and return their IDs."""
    if not IMAGE_PATHS:
        raise ValueError("Add at least one path to IMAGE_PATHS.")

    image_ids = []
    for image_path in IMAGE_PATHS:
        with image_path.open("rb") as image_file:
            response = requests.post(
                f"{API_URL}/projects/{project_id}/assets/images/",
                headers=headers,
                files={"images": (image_path.name, image_file)},
                timeout=60,
            )
        response.raise_for_status()
        image_ids.append(response.json()[0]["id"])
    return image_ids


def import_zillow_images(project_id: str, headers: dict[str, str]) -> list[str]:
    """Import Zillow images and return their IDs."""
    response = requests.post(
        f"{API_URL}/projects/{project_id}/property-import-jobs/",
        headers=headers,
        json={"url": ZILLOW_URL},
        timeout=60,
    )
    response.raise_for_status()
    wait_for_job(response.json()["links"]["self"], headers)

    response = requests.get(
        f"{API_URL}/projects/{project_id}/assets/images/",
        headers=headers,
        params={"page_size": 60, "ordering": "created_at"},
        timeout=60,
    )
    response.raise_for_status()
    payload = response.json()
    images = payload["results"] if isinstance(payload, dict) else payload
    return [image["id"] for image in images]


def create_shots(
    project_id: str,
    image_ids: list[str],
    headers: dict[str, str],
) -> None:
    """Create one shot for each image ID."""
    if not image_ids:
        raise RuntimeError("The project has no images.")

    response = requests.post(
        f"{API_URL}/projects/{project_id}/shot-batches/",
        headers=headers,
        json={"image_asset_ids": image_ids},
        timeout=60,
    )
    response.raise_for_status()


def generate_video(project_id: str, headers: dict[str, str]) -> str:
    """Generate the project video and return its URL."""
    response = requests.post(
        f"{API_URL}/projects/{project_id}/video-jobs/",
        headers=headers,
        json={},
        timeout=60,
    )
    response.raise_for_status()
    wait_for_job(response.json()["links"]["self"], headers)

    response = requests.get(
        f"{API_URL}/projects/{project_id}/assets/videos/",
        headers=headers,
        params={"tags": "render_full", "ordering": "-created_at", "page_size": 1},
        timeout=60,
    )
    response.raise_for_status()
    payload = response.json()
    videos = payload["results"] if isinstance(payload, dict) else payload

    if not videos:
        raise RuntimeError("The completed job has no rendered video.")

    video_url = videos[0].get("file") or videos[0].get("external_url")
    if not video_url:
        raise RuntimeError("The rendered video has no URL.")

    return video_url


def main() -> None:
    """Create a project, add images, and generate its final video."""
    token = os.environ["TENSORPIX_API_TOKEN"]
    headers = {"Authorization": f"Token {token}"}
    project_id = create_project(headers)

    if SOURCE == "images":
        image_ids = upload_images(project_id, headers)
    elif SOURCE == "zillow":
        image_ids = import_zillow_images(project_id, headers)
    else:
        raise ValueError("SOURCE must be 'images' or 'zillow'.")

    create_shots(project_id, image_ids, headers)
    video_url = generate_video(project_id, headers)
    print(video_url)


if __name__ == "__main__":
    main()
```
